Documentation versions

Choose server and library source independently. Every guide, HTTP reference and C# reference in a snapshot is generated from its pinned commits.

These combinations let you read the two sources together. They are not certified compatibility pairings. See the selected server's compatibility guide for its policy and recorded test evidence.

Finding your library build

A library SemVer, GitHub commit, s&box package revision and game revision are different identities. The same reported library version can cover several source commits. A repository .version file alone does not prove which commit s&box published.

For a GitHub install, match the source commit. For a Library Manager install, find the installed sboxcool.network-storage package revision and use a mapping only when publication evidence records that exact revision and commit. If no mapping is listed here, the matching published-package docs are not verified; do not assume the newest source matches your game. Existing games retain their bundled library until republished.
