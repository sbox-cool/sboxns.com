HTTP API reference

Every game-facing route the server answers, generated from its route definitions and checked against the HTTP contract tests (163 recorded requests). The game library calls these for you; use this page when you write tools, debug traffic or build a client in another language.

Authentication

  • Public key (sbox_ns_...) in x-public-key or the apiKey query parameter: game clients. Ships inside your game.
  • Player identity: x-steam-id plus an s&box auth token in x-sbox-token when the project requires player authentication.
  • Secret key (sbox_sk_...) in x-api-key or x-secret-key: editor sync, dedicated servers and management routes. Never ship it in a game build.
  • Client identity headers such as x-ns-library-version and x-ns-client-type are diagnostics, not authentication. See compatibility.

Errors use one envelope: {"ok": false, "error": {"code": "...", "message": "..."}}. Paths below use {projectId}-style placeholders; examples use the test variables (${projectId}, ${publicKey}).
