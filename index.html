From VPS to game

  1. Install your backend

    On a fresh Linux VPS with sudo access, this installs the server, creates a project and API keys, enables the HTTPS tunnel and starts the service.

    curl -fsSL https://github.com/sbox-cool/sbox-network-storage-server/releases/latest/download/install.sh \
  | sudo env SBOX_NS_PROJECT="My Game" SBOX_NS_TUNNEL=1 sh

    Keep the credentials printed by the installer private. For Windows, Docker, PostgreSQL or an existing installation, use the self-hosting guide.

  2. Point the library at your HTTPS name

    Use your project ID, public key and the generated hostname in the official Network Storage library.

    NetworkStorage.Configure(
    "YOUR_PROJECT_ID",
    "sbox_ns_YOUR_PUBLIC_KEY",
    "https://YOUR_NAME.sboxns.com" );

    Set the same Base URL and credentials in the editor Setup Tool. The secret key belongs only in editor tooling or trusted servers, never in a published game.

  3. Sync your project and own your database

    Author collections, endpoints and workflows in YAML Source, then push their definitions with the editor Sync Tool. Runtime player records live in SQLite or PostgreSQL on your server. Syncing definitions is not a database migration.

    Manage projects and keys, browse records and export backups from your owner dashboard.

Free HTTPS, without buying a domain

sboxns.com gives your server a stable name derived from its key. Cloudflare Tunnel connects to your server from the inside, so you do not need to expose the backend port publicly.

The tunnel is optional. You can use your own domain, certificate or reverse proxy instead. sboxns.com is a sister landing page of sboxcool.com, not a shared database or a central admin panel.

Where is my admin panel?

Visit https://YOUR_NAME.sboxns.com/login to sign in and /dashboard to manage your server. There is no /admin/login route. For initial setup or passwordless access, run sbox-ns admin login-link on your server and open its single-use link.

No lock-in. Clear boundaries.

The server does not require a sboxcool account, payment, email registration or usage reports. Anonymous install statistics and security emails are separate opt-ins. Your database stays on your machine.

Using the hosted name sends registration metadata to sboxcool and routes requests through Cloudflare. It is not a promise of zero third-party traffic. The connector also has its own crash reporting. For an independent deployment, use your own HTTPS setup and leave optional services disabled.

Each subdomain belongs to an independently operated server. Contact that game's operator about its player data. For hosted-name abuse, contact support with the hostname and evidence. Read the acceptable-use policy and privacy policy.
