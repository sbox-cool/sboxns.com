sboxns.com

Free HTTPS hostnames for self-hosted sbox Network Storage servers. No domain to buy, no account to create.

Get a name

Install the open source server, then enable the tunnel. Your server gets a stable address like abcd2345wxyz.sboxns.com derived from its own key.

curl -fsSL https://github.com/sbox-cool/sbox-network-storage-server/releases/latest/download/install.sh \
  | sudo env SBOX_NS_PROJECT="My Game" SBOX_NS_TUNNEL=1 sh

Already installed? Run sbox-ns tunnel enable and restart the service.

What these names are

Each subdomain points at one independently operated server, reached through a Cloudflare Tunnel. Those servers and their data belong to the people who run them, not to sboxcool.

Report abuse

Names are covered by the hosted names acceptable-use policy. To report a name, contact sboxcool support with the hostname and what you saw.
