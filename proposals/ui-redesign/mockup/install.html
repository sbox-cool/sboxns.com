Install

Linux VPS with sudo. About two minutes.

1

Install the server

Public IPNo open portsWindows

Name like NAME.n1.sboxns.com. Ports 443 and the HTTP check port must be reachable.

$ curl -fsSL https://github.com/sbox-cool/sbox-network-storage-server/releases/latest/download/install.sh \
  | sudo env SBOX_NS_PROJECT="My Game" SBOX_NS_DNS=1 \
      SBOX_NS_ACME_EMAIL="you@example.com" SBOX_NS_ACCEPT_LETSENCRYPT_TERMS=1 sh
Checksum verificationLet's Encrypt termsDepends on sboxns.com?Read install.sh
2

Keep the printed credentials

Project ID, public key, secret key and HTTPS address. Print them again any time:

$ sudo sbox-ns quickstart "My Game"
3

Open the dashboard

$ sudo sbox-ns admin login-link
4

Connect the s&box editor

Library 1.0.309133+

Editor > Network Storage > Setup, then Sync Tool.

NetworkStorage.Configure( "YOUR_PROJECT_ID", "sbox_ns_YOUR_PUBLIC_KEY", "https://YOUR_HOSTNAME" );
