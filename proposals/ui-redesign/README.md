# sboxns.com redesign proposal

Assets for the site redesign feature request. Do not merge this folder into `main`: GitHub Pages would publish it.

- `before/`: the current `index.html` at 1440x900 and 390x844.
- `after/`: the proposed home and install pages, rendered from `mockup/`.
- `mockup/`: static HTML using the proposed near-black tokens and solid icons (`icons.json`). Open `home.html` or `install.html` in a browser. Run `python3 generate.py .` inside `mockup/` to regenerate the pages.

The gallery thumbnails in the mockup are the proposed owner console screens from the sbox-network-storage-server proposal.
