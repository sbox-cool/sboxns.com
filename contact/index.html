Everything Network Storage ships as open source. Start with the code and the community; the maintainers are one link further down.

Open source

All Network Storage content lives on GitHub: the self-hosted server and the s&box game library. Bugs, feature requests and contributions go through issues and pull requests there, where the work is reviewed in the open. Releases are published on the server releases page.

Community

For setup help, game-backend questions and discussion, join the Network Storage Discord. For the wider s&box community, there is also the s&box Cool Discord.

Primary maintainers

sboxns.com is run by sboxcool. For anything that should reach the primary maintainers directly, including security reports and hosted-name abuse, see sbox.cool/contact for contact information.
